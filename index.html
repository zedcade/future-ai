Import / export data

Import real historical data (for example 2020–2027) to extend charts before 2026, or export current sliders and imported data. JSON is used because metrics and years may be sparse.

  • historical.compute_relative — compute stock, relative to 2026=1×
  • historical.capex_usd_billion — annual hyperscaler capex
  • historical.energy_twh, benchmark_pct, horizon_minutes
  • historical.token_relative, cost_relative
  • historical.token_cost_usd_per_million — actual blended USD cost per 1M tokens
  • historical.train_flop_relative — largest frontier training run, relative to 2026=1×
  • historical.chip_capacity_kwafers — advanced-packaging capacity, thousand wafers/month
  • historical.private_investment_usd_billion — global private AI investment
  • historical.capex_usd_billion_us, capex_usd_billion_china, capex_usd_billion_eu — regional capex, rest-of-world is the remainder
  • historical.water_billion_liters — data-center water usage
  • anchors_override.token_cost_usd_per_million, train_flop_2026, chip_capacity_kwafers_2026, private_investment_2026_usd_billion — editable 2026 absolute anchors
  • Each metric is a sparse {"year": value} object. Omit metrics/years you do not have. Only values before 2026 are used as history — later years in your file are ignored (with a warning) rather than treated as historical.
